# Privacy and Personal Data

This document describes how Stellaris - Universum Infinitum - Star Names at https://github.com/hmlendea/stellaris-ui-star-names handles personal data. The mod is a collection of text files containing star, nebula, asteroid, and black hole names for the game Stellaris. It does not collect, process, store, or transmit any personal data.

## 🔎 What This Document Covers

This document describes how Stellaris - Universum Infinitum - Star Names at https://github.com/hmlendea/stellaris-ui-star-names handles personal data. It covers the application behaviour and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

## 📥 Data We Handle

### Data Provided to the Application

No personal data is requested, provided, or accepted by the mod.

### Data Generated or Collected by the Application

No personal data is generated or collected automatically by the mod.

### Data Received from Integrations

No personal data is received from integrations or third parties.

## 🧭 Processing and Use

The application processes the data described above for these verified functions:
- Providing additional star, nebula, asteroid, and black hole names for Stellaris — No personal data involved

## 🗄️ Storage, Retention, and Deletion

The mod consists of static text files containing name lists. No personal data is stored, retained, or deleted by the mod. For self-hosted deployments (manual installation), the instance operator controls the mod files in their Stellaris mod directory.

## 🔗 External Processing and Integrations

The application has no built-in external data transfer. The mod only reads local text files and provides names to Stellaris during game generation.

| Service or integration | Purpose | Data involved | Configuration or documentation |
|-----------------------|---------|---------------|--------------------------------|
| None | N/A | N/A | N/A |

## 🛡️ Data Protection and Security

The mod contains only static text files with fictional and real astronomical names. No personal data is processed, so no specific safeguards are required. For self-hosted deployments, the instance operator is responsible for their Stellaris installation, mod directory, and any game data.

The original maintainers are not responsible for changes, modifications, or privacy issues introduced by downstream forks.
